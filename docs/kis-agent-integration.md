# KIS 연구 앱 저장소 통합

2026-10-16 KST. 별도 `/workspace/kis-self-improving-agent`에서 개발했던 코드·테스트·문서·비밀 없는 설정을 `apps/kis-agent`로 가져왔다. 이제 개발 기준은 momentum-study checkout이다. 원래 개발 폴더는 이전 기록으로 보존하며 Git에 중복 추가하지 않는다.

기존 `src/momentum`, 루트 테스트·골든 픽스처·가설 설정·명세를 보존했다. 기존 미국 보통주 H1~H4와 국내 주식·ETF 연구 앱은 다른 시장·통화·정책을 사용하므로 패키지와 환경을 분리한다. 기존 엔진을 KIS 프로토타입으로 대체하거나 투자 판정을 이어 붙이지 않는다. 현재 범위는 자동 주문보다 로직과 자동 개선의 선행 개발이다.

## 통합 시 보완

1. KIS 선별 평가·로컬 재생의 최초 주문 수량을 전일 종가 기준으로 확정한다. 다음 시가 하락을 보고 최초 매수 수량을 늘리지 않는다. 다음 시가는 실제 체결 가격과 이미 계획된 수량의 현금·위험 축소에만 사용한다. 시가가 없으면 전일 종가로 체결하지 않는다.
2. 최종 구간 평가 전 `evaluation_manifests`에 전략·데이터·비용·정책 해시를 저장한다. 스키마 v5는 기존 원장·실험·소비 기록을 보존하고 이 테이블을 추가한다. 평가가 중단돼도 소비 기록과 동결 계약이 남는다.
3. 루트 pytest는 원래 `tests/`를, 앱은 별도 unittest를 실행한다. 앱의 lint 설정을 명시하고 import·미사용 변수 경고를 정리한다. 루트 의존성을 KIS 앱에 강제로 추가하지 않는다.
4. 키·토큰·환경·생성 결과·원장 DB를 제외하고 소스만 반영한다. `.gitignore`를 보강한다.

## 검증 범위

- 기존 미국 엔진: 기본 테스트 190개, slow 표시 테스트 1개는 기본 설정에 따라 제외.
- KIS 앱: 기존 119개와 저장소 불변 조건 회귀 3개, 총 122개.
- 타입 검사: 기존 `mypy src`.
- lint: 저장소 전체 `ruff check`, 각 프로젝트 설정 적용.
- 앱 통합: 일반 합성 연구의 기존 전략 유지, 별도 성공 분기 fixture의 연구 전략 갱신·새 전진 사이클, 주문·계좌 생성 0회.

저장소 연결·경제 불변 조건 회귀는 실제 KIS 인증·주문·실제 시장 수익성을 검증한 결과가 아니다. 기존 평가기의 명세 미정 부분이나 잠긴 H1~H4 holdout을 이번 통합으로 해제하지 않는다.

## 명령

```bash
uv run pytest -q
uv run mypy src
uv run ruff check
uv run --directory apps/kis-agent python -m unittest discover -s tests -v
uv run --directory apps/kis-agent python -m examples.offline_logic
```

테스트용 생성 산출물은 앱의 artifacts 폴더에 남으며 Git에서 제외한다. 실제 연구에서는 이전 빌드의 데이터·평가 소비 기록을 보존하고 검토 가능한 버전 전환을 해야 한다.
