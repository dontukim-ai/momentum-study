# 진입 시점 서술 통계: 일시 투자와 분할 매수 (2026-11-03, 사용자 요청)

사용자 질문(2026-11-03): "진입을 언제 해야 되는가에 대한 문제가 남지 않아?" 지금까지 진입 시점을 맞히는 신호는 찾지 못했다(v23·v24·v27~v30). 그래서 이 문서는 신호를 찾지 않는다. **예측 없이 진입 방식을 정할 때 필요한 숫자**를 한국 자료로 낸다.

**이 문서의 성격**
- 전략 시험이 아니다. 판정이 없고, 시험 장부에 올리지 않는다. 결과로 규칙을 고르지 않는다.
- 아래 정의는 자료를 읽기 전에 정했다. 결과를 본 뒤 정의를 바꾸지 않는다.

## 1. 자료

- 금융위 API는 2020-01부터라 5·10년 보유를 볼 수 없다. 그래서 KIS 읽기 전용 일별 시세를 쓴다(사용자 승인 2026-11-03: `apps/kis-agent`의 읽기 전용 조회에 일별 경로 두 개 추가, 주문 기능은 건드리지 않음).
  - KOSPI 200 지수(업종 코드 2001, `FHKUP03500100`): 가능한 가장 이른 날부터
  - 069500(`FHKST03010100`, 원주가): 2002-10 상장부터. 지수 결과를 실제 ETF로 대조하는 용도다.
- 수집: `tools/kis_daily_history.py`. 맥에서 1회, `data/kis/daily-history/`에 저장한다(Git 밖, 재배포 금지).
- **한계:** 종가 기준이고 배당·분배금이 빠져 있다(연 1~2%p 낮게 나온다). 비용과 세금이 없다. 분할 매수의 대기 현금에는 이자가 없다(분할 매수에 불리). 배당 누락은 분할 매수에 약간 유리하다. 두 효과는 방향이 반대다.

## 2. 정의 (`tools/entry_timing.py`)

1년은 252세션, 1달은 21세션이다. 자료 안의 모든 시작일 s에 대해 계산한다.
- **일시 투자:** s 종가에 전부 사고, H년 뒤 종가에 평가한다.
- **분할 매수 M개월(M = 6, 12):** s, s+21, ..., s+21(M−1) 종가에 같은 금액씩 산다. 같은 끝날에 평가한다.
- **보유 기간 H:** 1, 2, 3, 5, 10년.
- **보고:**
  - 연환산 수익의 10%·50%·90% 분위, 최솟값·최댓값, 손실 비율
  - 일시 투자가 분할 매수를 이긴 시작일 비율
- **회복:** s 뒤에 종가가 처음으로 s 종가 이상이 될 때까지의 세션 수.
  - N년 안 회복 비율(N = 1, 3, 5)은 뒤에 N년 이상 자료가 있는 시작일만 센다.
  - 아직 회복하지 못한 시작일은 따로 센다.
- **주의:** 시작일 창이 겹치므로 시작일 수는 독립 표본 수가 아니다. 서로 이웃한 시작일의 결과는 거의 같다.

## 3. 실행

맥에서 순서대로 한다(읽기 전용, 주문 없음).

    uv run --extra agent python tools/kis_daily_history.py --end 2026-10-30
    uv run python tools/entry_timing.py --series data/kis/daily-history/kospi200.json \
        --series data/kis/daily-history/069500.json

**읽는 법 (판정이 아니다)**
- 일시 투자가 분할 매수를 이기는 시작일이 모든 보유 기간·시리즈에서 56~63%였다. 평균적으로 시장이 오르므로 대기 현금이 손해다. 분할 매수는 중앙값을 낮추는 대신 아래 꼬리(p10)를 1년 보유에서 크게 줄였다(kospi200 −23.9% → −14.2%). 보유 기간이 길수록 이 차이는 사라졌다.
- 손실 비율은 보유 기간이 길수록 줄었다(kospi200 1년 39% → 10년 6%). 진입 방식보다 보유 기간이 결과를 더 크게 갈랐다.
- 대기 현금의 이자와 배당이 빠져 있다. 이자는 분할 매수에, 배당은 일시 투자에 유리한 방향이다.
- 시작일 창이 겹치므로 비율은 독립 표본의 비율이 아니다. 1990년대 이후 한국 한 시장의 역사 하나다.
