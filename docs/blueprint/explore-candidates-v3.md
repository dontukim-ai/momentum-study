# 탐색 후보 공간 v3: 유동성 상위 종목·자본 1억 원 (2026-10-23 사용자 결정)

작성 2026-10-23. 근거는 v2c·v2d·v2e 결과(explore-candidates-v2 §10)다. 이 문서는 결과를 본 뒤 후보 공간을 바꾸는 제안이라, 새 연구로만 적용하고 기존 연구의 사전 등록은 바꾸지 않는다. 결과를 본 뒤 아래 값을 바꾸지 않는다.

## 1. 왜 바꾸는가

- v2 매월·상위 20종목은 검증 구간 8개 복리 −40.1%, 전진 관찰 2020-11~2024-06 −51.3%(낙폭 57.7%)였다. 같은 기간 KODEX 200 기준(투자 약 38%)은 각각 −8.0%, +4.0%였다.
- 유동성 하한(20일 평균 거래대금 1억 원)이 낮아, 직전 급등한 소형주가 상위를 채우고 반전 손실을 냈다(§7.1, §9).
- 자본 100만 원은 종목당 예산이 작아 고가 대형주를 1주도 사지 못했고, 동일 비중 기준 전략도 현금과 같아졌다(§10.3).

## 3. 코드 변경

- `apps/kis-agent` `SelectionPolicy`의 연구용 자본 상한을 1,000,000원에서 **100,000,000원**으로 올렸다(`RESEARCH_CAPITAL_LIMIT`). 기본값은 1,000,000원 그대로다. 실주문 상한 `kis_real.REAL_CAPITAL_LIMIT`(1,000,000원)과 모의 실행 승인 상한 `MarketProfile.capital_cap`(1,000,000원)은 바꾸지 않았다. kis-agent 소스 해시가 바뀌므로 모든 전략 버전 ID가 이전 연구와 달라진다.
- `tools/historical_policy.py`에 `--min-average-turnover`, `--capital`, `--max-order-notional`을 더했다. 옵션이 없으면 이전과 같은 정책이 나온다.

## 4. 해석할 때 주의할 점

- 거래대금 하한은 원화 절대값이라 시장 거래대금이 커지면 같은 하한을 넘는 종목 수가 늘어난다. 시점별 적격 종목 수를 함께 보고한다.
- 자본이 100배가 되어 거래량 참여 상한(전일 거래량의 1%)이 실제로 걸릴 수 있다. 체결 이벤트의 `cancelled_volume_cap`·`reduced_cash_or_risk`를 함께 본다.
- 5종목은 분산이 낮아 구간별 결과의 변동이 크다.
- 데이터 한계는 explore-candidates-v2 §10과 같다(E1 미검증 입력, 미반영 기업행동, 실비용 미확정, ETF 분배금 미반영). 투자 판단에 쓰지 않는다.

## 5. 첫 실행 실패와 원장 결함 수정 (2026-10-23)

`explore-v3-liquid5-1e8` 첫 실행(빌드 fae37d2)은 사이클 0 검증 구간 평가 중 `Independent ledger NAV residual -186.545…` 오류로 멈췄다(사이클 FAILED, 예산 1회 소비, 재실행하지 않음).

- 원인: 원장 결함. 무상증자 권리락 뒤 신주 상장 전(pending)에 같은 종목을 추가 매수하면, 평가 단가 혼합이 상장 주식 수만 가중했다. 보유 평가액은 pending을 포함하므로 NAV가 pending × (체결가 − 평가단가) / 전체 수량만큼 어긋났다. 실례: 075580(0.5 무상증자, 권리락 2020-10-30, 상장 11-23) 24주 보유 + pending 12주 상태에서 11-02 9주 매수 → 36 × (6,847 − 6,790) / 11 = 186.545원.
- 드러난 경로: 자본 1억 원에서 처음으로 실제 매수를 하게 된 `equal_weight_eligible` 기준(약 300종목 보유)이 이 경우를 만났다. 전략(5종목)·시장 ETF·현금 평가는 통과했다(읽기 전용 진단 스크립트로 확인).
- 수정: 매수 시 평가 단가 혼합 가중에 pending 수량을 포함한다(`ledger.apply_fills`). 같은 숫자의 회귀 테스트를 추가했다. 이 경우를 만나지 않은 이전 연구 결과는 바뀌지 않는다.
- 재실행은 새 연구 DB로 사용자 승인 뒤에 한다.

### 7.5 해석

- 관찰 장부 +101.7%는 소수 종목의 한두 달 급등(상위 5종목이 순이익의 124%)과 2023년 한 해(+116.7%)에서 나왔다. 종목 승률은 41%이고 2022년 낙폭은 53%였다.
- 같은 전략이 검증 구간 복리 −48.0%, 연속 장부 +101.7%로 갈린 것은 전략의 우위라기보다 집중 포트폴리오의 경로 의존과 구간 표본 차이로 보는 것이 맞다. 사전 등록 게이트로는 개선이 아니다.
- 미확인: 상위 수익 종목의 급등이 실제 가격인지, 입력에 빠진 기업행동(병합·감자 등) 때문인지 확인하지 않았다. 모멘텀은 그런 가격 단절을 우선 고르므로 투자 판단 전에 반드시 확인해야 한다. 투자 판단에 쓰지 않는다.
