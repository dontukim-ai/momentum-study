# v19 5분봉 패턴 방향 학습 (2026-10-29 사전 등록, 사용자 요청, 데이터를 보기 전)

사용자 요청(2026-10-29): 한 종목의 **직전 분봉 5개와 거래량**으로 **다음 5분의 방향**을 예측하는 패턴을 학습하는 기능을 만든다.

- 처음 요청은 삼성전자(005930)였다. 사용자 결정(같은 날)으로 왕복 거래비용을 고려해 ETF로 바꿨다.
  - 삼성전자는 매도세 0.20%가 붙어 왕복 비용이 25~30bp 수준이다.
  - 국내 주식형 ETF는 매도세가 없어, 대형 ETF 왕복 비용이 약 5~6bp다(v12b §7).
  - 삼성전자 분봉은 비용 측정일(며칠)에만 받아서 1년치 이력도 없다.
- 이것은 통계 실험이다. 매매 규칙이 아니고, 주문도 없다. v12와 같은 방식이다.
- 도구는 `tools/pattern_lab.py`다. v12 도구(`direction_lab`)의 분봉 격자, 채점, 모형 적합을 그대로 가져다 쓰고 복제하지 않는다.

## 1. 데이터

- **종목:** 069500 KODEX 200 한 종목이다. 확정 ETF 30종 중 거래가 가장 많고, 비용 측정 대상이다. 삼성전자 비중이 큰 코스피 200을 따른다.
- **개발 구간:** 2025-10-27~2026-06-30. `development_bars`로 읽는다.
- **v11 검증 구간(2026-07-01~10-23):** 열지 않는다.
- **전진 구간:** 2026-10-26 이후. 동결 뒤 판정에만 쓴다.

## 2. 분봉 5개 (분 i까지의 값만)

- **분봉:** KIS 1분봉의 시가·고가·저가·종가·거래량이다.
  - 종가와 거래량은 v12 격자와 같다(마지막 체결가, 체결 없는 분은 직전 종가 유지·거래량 0).
  - 체결이 없는 분은 시가·고가·저가도 직전 종가로 둔다. 거래가 없었으니 움직임도 0이라는 정의이고, 값을 채워 넣는 것이 아니다.
- **표본 시점:** 09:30~15:14의 매분이다.
  - 09:30부터인 이유: 거래량 기준 창(직전 20분)에 09:00 시가 동시호가가 들어가지 않게 한다.
  - 15:14까지인 이유: 5분 뒤가 15:19 안에 들어와야 한다.
- **신호 25개:** 분 i−4~i의 다섯 봉 각각에 대해 아래 다섯 값을 쓴다.

  | 신호 | 정의 | 잘라내는 범위 |
  |---|---|---|
  | ret | 종가 ÷ 직전 분 종가 − 1, bp | ±100 |
  | body | (종가 − 시가) ÷ 시가, bp | ±100 |
  | upper | (고가 − max(시가, 종가)) ÷ 시가, bp | ±100 |
  | lower | (min(시가, 종가) − 저가) ÷ 시가, bp | ±100 |
  | vol | log((거래량 + 1) ÷ (분 i−24~i−5 평균 거래량 + 1)) | ±5 |

- **대상:** 다음 5분 방향, sign(종가[i+5] ÷ 종가[i] − 1)이다. 오름·같음·내림 셋이고, 정확도는 오르거나 내린 경우로만 계산한다. 같음 비율은 따로 낸다.

## 3. 모형 (4개, 모수 고정)

| 모형 | 내용 |
|---|---|
| BASE | 학습 기간에 더 많았던 방향 |
| PATTERN | 다섯 봉의 ret 부호(오름·같음·내림)에 거래량 상태(다섯 vol 평균 > 0이면 1)를 더한 486가지 패턴. 패턴마다 다음 5분이 오른 빈도를 라플라스 보정으로 구한다(v12 MARKOV 적합 재사용) |
| LOGIT | 25개 신호의 L2 로지스틱 회귀(v12 LOGIT 적합 재사용, 같은 벌점) |
| KNN | 25개 신호를 학습 기간 평균·표준편차로 표준화한다. 유클리드 거리로 가장 가까운 과거 200개 표본(오르거나 내린 것만)에서 오른 비율을 구하고, (오름 + 1) ÷ (200 + 2)로 보정한다 |

예측확률이 정확히 0.5면 예측하지 않는다(v12와 같다).

## 4. 개발 구간 검증 (탐색)

- **걷기식:** v12와 같다. 첫 40일로 학습하고 다음 20일을 예측한 뒤, 지금까지의 모든 날로 다시 학습하기를 반복한다.
- **지표:** v12 `score`를 그대로 쓴다.
  - 정확도와 Wilson 구간, 이항 p, 날짜 단위 t
  - 브라이어 점수, 로그손실, 보정표
  - 확신 구간별 정확도
  - 크기 가중 적중, 예측 1회당 부호 수익(bp, 비용 전)
- **해석:** 개발 결과는 탐색일 뿐이다. 판정은 §5의 전진 채점으로만 한다.

## 5. 동결과 전진 판정 (고정)

- **동결:** `freeze`로 개발 구간 전체를 학습해 한 번만 쓴다.
  - KNN은 학습 표본 자체가 모형이다. 그래서 동결 파일은 저장소가 아니라 `data/kis/pattern-v19/model.json`에 둔다(KIS 자료 재배포 금지).
  - sha256만 이 문서와 시험 장부에 적는다.
- **채점:** `score`는 2026-10-26 이후 날만 받는다.
- **판정 시점:** 전진 거래일이 60일 쌓인 뒤 처음 채점할 때 한 번 판정한다. 그 전의 채점은 보고만 한다.
- **판정 기준 (모형별):**
  1. **방향 정보가 있다:** 아래 둘을 모두 만족해야 한다.
     - 날짜 단위 t ≥ 2.13. 세 모형(BASE 제외)의 단측 본페로니 0.05/3에 해당한다.
     - 정확도가 같은 날들의 BASE 정확도보다 높다.
  2. **비용을 넘는다 (보고, 1번을 통과한 모형만):** 예측 1회당 부호 수익(bp)을 069500 장중 왕복 비용 추정(비용 측정 v10의 중앙값)과 비교한다.
     - 실제 매매는 매분 겹쳐 사고팔 수 없다. 그래서 이 비교는 상한일 뿐이고, 매매 규칙은 따로 등록해야 한다.
- 결과를 본 뒤 신호, 모형, 모수, 기준을 바꾸지 않는다. 바꾸려면 새 버전으로 등록하고 전진 채점을 처음부터 다시 한다.
- **시험 장부:** 4칸(BASE, PATTERN, LOGIT, KNN; 모두 h5)을 예측 칸(`forecast`)으로 등록한다. 전략 자리는 차지하지 않는다. 등록 뒤 장부는 65개 시험이고, 전략 승격 기준은 t ≥ 3.17이 된다.

## 6. 미리 밝혀 둘 점

- **v12와 겹친다.** v12는 30개 ETF를 합쳐 5분 방향을 이미 시험했다.
  - 개발 구간 결과는 LOGIT h5 52.68%, 날짜 t 11.4였다. 신호는 직전 1분 부호, 5분 수익, VWAP, 거래량, 069500, 시각이었다.
  - v12b에서는 5분 수익 예측의 상위−하위 차이가 3.6bp로, 왕복 비용보다 작았다.
  - 이 실험은 그 연장이다. 바뀐 것은 세 가지다: 봉 모양(몸통·꼬리)과 다섯 봉의 거래량을 그대로 쓰는 것, 패턴표와 KNN, 한 종목만으로 학습하는 것.
- **체결가 반등:** 종가는 그 분의 마지막 체결가라서 매수·매도 호가를 오간다. 이것이 1분 신호와 5분 대상에 모두 섞인다(v12 §6~7). 과거 호가가 없어 중간가로 바꿀 수 없다. 그래서 정확도가 높게 나와도 이 착시가 섞여 있을 수 있다.
- **한 종목이라 표본이 작다.** 개발 하루 약 345점, 166일이다. 5분 대상은 이웃한 분끼리 겹치므로 실제 독립 표본은 훨씬 적다. 날짜 단위 t를 우선하는 이유다.

## 7. 실행 (맥)

```
uv run python tools/pattern_lab.py eval   --bars data/kis/minute-history
uv run python tools/pattern_lab.py freeze --bars data/kis/minute-history --model data/kis/pattern-v19/model.json
uv run python tools/pattern_lab.py score  --bars data/kis/minute-history --model data/kis/pattern-v19/model.json
```

- 전진 채점에는 2026-10-26 이후 069500 분봉이 필요하다. `tools/kis_minute_history.py`로 069500만 받은 유니버스 파일을 써서 모은다(KIS 보관 기간 안).
