# v12b 수익률 예측 실험실 (2026-10-27, 데이터를 보기 전 사전 등록, 사용자 승인)

사용자 요청(2026-10-27): 방향 예측에 **강도**도 넣는다. v12(방향)는 그대로 두고, 방향과 크기를 함께 담은 **수익률 자체**를 예측하는 실험을 따로 등록한다. 수익·비용·주문은 다루지 않는다. 데이터·격자·신호·걷기식 검증·v11 검증 구간 봉인은 v12와 같다. 도구는 `tools/return_lab.py`이고, v12의 격자·신호 계산(`direction_lab.build`)을 그대로 쓴다.

## 1. 예측 대상

- **수익률:** 분 i에서 h분 뒤 수익률을 bp로 나타낸 값(h = 1, 5, 30). 값이 0인 경우도 포함한다.
- **크기:** 같은 수익률의 절댓값. 방향 없이 "얼마나 움직일지"만 본다. 변동성은 직전 변동성을 따라가는 경향이 강해 잘 맞을 가능성이 크다. 그래서 방향 예측과 섞지 않고 따로 보고한다.

## 2. 모형

- **ZERO:** 항상 0을 예측한다. 수익률 오차의 기준이다.
- **MEAN:** 학습 기간 평균 수익률을 예측한다.
- **RIDGE:** v12 신호 8개를 표준화하고 L2 선형 회귀(α = 1)로 수익률을 예측한다. 종목 합동이다. 학습할 때만 목표값을 학습 구간의 1%·99% 분위수로 자른다. 평가는 자르지 않은 값으로 한다.
- **SIZE:** 수익률 절댓값을 L2 선형 회귀(α = 1)로 예측한다. 신호는 다음 8개다.
  - 직전 60분 1분 수익률 표준편차(bp)
  - 직전 3분 방향의 절댓값
  - 5분 수익률·VWAP 이탈 z의 절댓값
  - 로그 거래량 비율
  - 시각

## 3. 검증과 지표 (고정)

걷기식 검증은 v12 §4와 같다. 첫 40일로 학습하고 20일마다 다시 학습한다. 칸은 모형 × 기간이다.

- **IC:** 예측값과 실제값의 순위 상관(스피어만)이다.
  - 날짜별 IC의 평균과 날짜 단위 t를 낸다. 예측이 30개 이상이고 값이 모두 같지 않은 날만 쓴다.
  - 전체를 합친 IC도 낸다.
- **10분위 차이:** 예측 상위 10%와 하위 10%의 실제 평균 수익 차이(bp)다. 날짜별로 나눠 계산한 값의 평균과 날짜 단위 t를 낸다. 비용 전 값이다.
- **R²(표본 밖):** 1 − 예측 오차 제곱합 ÷ "0 예측" 오차 제곱합이다. 0보다 크면 0으로 예측할 때보다 낫다. SIZE는 학습 평균 크기 예측과 비교한다.
- **해석 기준:**
  - "수익률을 맞힌다"는 RIDGE의 날짜별 IC t ≥ 2이고 R² > 0일 때만 말한다.
  - 다중검정은 RIDGE 3칸에 본페로니를 적용한다. p는 날짜별 IC t의 단측 p다.
  - h = 1분은 v12 §8처럼 호가 반전이 섞여 있어 보고만 한다.
  - SIZE는 따로 보고하고, 수익률 예측의 근거로 쓰지 않는다.
  - ZERO와 MEAN은 한 학습 구간 안에서 값이 일정하므로 IC를 내지 않는다.

## 5. v12 채점 지표 추가 (2026-10-27, 전진 데이터를 보기 전)

v12 모형은 바꾸지 않고, 채점 지표만 늘렸다(`direction_lab.score`). 판정 기준(v12 §4·§8)은 그대로이고 아래 지표는 보고 항목이다.
- **확신도별 적중률:** |p − 0.5| 구간 [0, 0.02), [0.02, 0.05), [0.05, 0.10), [0.10, 0.50]마다 예측 수와 적중률을 낸다.
- **크기 가중 적중:** Σ(예측 방향 × 실제 수익) ÷ Σ|실제 수익|이다. −1~1 사이이고, 0이면 우위가 없다.
- **예측당 방향 수익:** 예측 방향 × 실제 수익의 평균(bp, 비용 전)과 날짜 단위 t다.
- **큰 움직임 적중률:** 실제 움직임 크기 상위 25%에서의 적중률이다.
