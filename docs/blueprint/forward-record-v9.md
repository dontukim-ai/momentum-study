## 3. 일정

- **시작:** 2026-10-21(어떤 연구도 보지 않은 첫 세션). 그 이전 데이터는 지표 계산을 위한 준비 기간으로만 쓴다.
- **매월:** KRX KIND 파일(관리종목·거래정지·상장폐지)을 사람이 내려받는다. 맥에서 입력 갱신(`tools/forward_update.py`)을 돌리면 마지막 단계에서 평가(`tools/fwd_record.py`)까지 실행된다(읽기 전용, 예산 없음, 기존 artifacts 덮어쓰기 없음). 결과는 이 문서 §5에 한 줄씩 추가한다.
- **도구 (§6):** 두 도구는 승인 뒤 다시 썼다. 판정 기준·대상은 도구를 쓰면서 바꾸지 않는다.
- **중간 보고:** 2027-04(약 6개월). 보고만 하고 판정하지 않는다.
- **판정:** 2027-10(약 12개월).

## 4. 판정 기준 (12개월, 결과 전 고정)

각 S에 대해 아래 둘을 모두 만족하면 "계속 기록할 후보"로 남긴다.
- (a) 순수익 ≥ R2(ETF 95% 보유) 순수익
- (b) 최대 낙폭 ≤ R2 낙폭 × 1.5

12개월(약 245세션)은 표본이 작다. 그래서 이 판정은 채택이 아니라 "다음 12개월에도 기록할지"만 정한다. S가 7개라 하나쯤은 우연히 통과할 수 있으므로, 통과한 것만이 아니라 7개 모두를 함께 보고한다. 실주문은 하지 않는다.

### 4.1 연구 종료 기준 (2026-10-27 사용자 결정, 판정 결과를 보기 전)

2027-10 판정에서 다음을 함께 본다. 대상은 v9 S1~S7과, 분봉 연구에서 전진 기록(S2)에 오른 후보(v11 §10)다.

- **기본 운용을 바꾸는 조건:** 같은 기록 기간에 비용 뺀 순수익 ≥ R2 순수익이고, 최대 낙폭 ≤ R2 낙폭 × 1.5인 대상이 하나 이상 있어야 한다. §4 (a)(b)와 같은 기준이다.
- **그런 대상이 없으면:** 기본 운용은 **저비용 지수 ETF 보유**로 결론 낸다. 이 저장소의 예측·전략 연구는 그 결론을 뒤집을 증거가 나올 때만 다시 연다.
- **다시 여는 조건:** 다음 중 하나다.
  1. 이미 기록 중인 대상이 미리 정한 판정을 통과한다. 예: v12·v12b 전진 채점, 분봉 S2 후보의 12개월 판정.
  2. 사용자가 새 가설을 새 데이터 예산과 함께 따로 승인한다.
- **분봉 후보(예: C5-A)에 대해:** 노출이 0.5라 상승장에서는 R2 순수익을 넘기 어렵다. 이런 후보는 v11 §10 기준을 통과하면 "계속 기록"으로 남는다. 하지만 위 조건을 넘지 못하면 기본 운용을 바꾸지 않는다.
- **연구 보류:** 그때까지 새 연구는 열지 않고 기록만 한다(v13 §11). 판정 결과를 본 뒤 이 기준을 바꾸지 않는다.

## 6. 기록 도구 (2026-10-26, 첫 기록 전 고정)

explore v6 전진 입력 조립(맥 `fwd-build*.sh`)과 v7 재무 조립(`v7-build.sh`), C1·C3·C4 평가 스크립트를 저장소 도구로 옮겼다. 첫 실제 실행 전에 고정하고, 바꾸면 기록을 새로 시작한다.

**평가 `tools/fwd_record.py`.** 모든 정책을 `config/forward-v9/base-policy.json`(v6 연구 정책, 맥 `artifacts/explore-v6-forward/policy.json`과 같은 내용)에서 각 연구가 바꾼 그대로 다시 만든다. v7·C1·C3 정책이 맥의 실제 연구 정책과 같은지는 테스트가 확인한다(`tests/fixtures/forward-v9/`). 아홉 대상을 2026-10-21부터 입력의 마지막 세션까지 현금에서 시작해 평가한다. 출력은 표와 JSON 한 줄이며 대상별 정책 해시와 입력 지문(`data_bundle_id`)을 함께 낸다. §4 기준(a)(b)는 참고로만 표시하고 판정은 2027-10에 한다. 합성 입력(12종목 + 069500, 재무·주식수 포함)으로 CLI까지 끝까지 실행했다. 테스트는 C1(S5)을 뺀 여덟 대상이 거래하는지 확인한다(S5는 추세 조건에 따라 거래가 없을 수 있다).

**입력 갱신 `tools/forward_update.py`.** 다음 명령으로 실행한다. `--end`는 KIND 파일을 내려받은 날이다.

    uv run --extra agent python tools/forward_update.py --end <YYYY-MM-DD> --kind data/krx/kind/<YYYY-MM-DD>

- 순서: FSC 주식·ETF 시세 수집 → OpenDART I·B·A 공시목록 수집 → 달력 → 기준가 조정 → 분할 → 배당 → 무상증자·감자 → 배당 행위 → 종목 상태 → 시세 변환 → 품질 선별 → 기업행동 병합 → 069500 지수명 확인 → 기준 ETF → 조립 → 품질 보고 → 상장주식수 → 재무 수집·조립 → 평가.
- 첫 달은 이전 입력으로 `data/krx/research-fwd-full`(기본값)을 쓰고, 둘째 달부터는 `--previous data/krx/fwd9/<지난 end>/research`를 준다.
- 출력은 새 디렉터리 `data/krx/fwd9/<end>/`에만 쓴다. 이미 있으면 멈춘다. 원시 캐시(`data/krx/raw`)에는 새 날짜만 더해진다. 공시목록은 저장된 마지막 구간 다음 날부터 받아 구간이 겹치지 않는다.
- 멈추는 조건:
  - 실행 시각이 `--end` 다음 평일 14:00 KST보다 이르다. FSC는 다음 영업일 13:00에 공개한다. 공개 전에 받은 빈 날은 다시 받지 않으므로, 나중에 휴장일로 굳어진다.
  - `--end`에 주식·ETF 시세가 없거나, 달력이 이전 세션을 그대로 잇지 않거나 `--end`까지 가지 않는다.
  - 이전 입력의 마지막 세션까지 가격 행이 하나라도 달라졌다.
  - 069500 지수명이 `코스피 200`이 아니다.
- 보고만 하는 것: 이전 끝 이후의 빈 평일 목록(휴장일인지 사람이 KRX 휴장일과 대조한다), 이전 입력 대비 기업행동 차이.
- 배당·무상증자·감자 단계는 처리 못 한 공시가 있으면 종료 코드 1을 낸다. v6 조립과 같이 요약 줄과 산출물이 있고 Traceback이 없을 때만 받아들인다.
- KIND: `--kind`에는 그달 내려받은 관리종목·매매거래정지·상장폐지 파일을 하나씩 둔다. 이전 다운로드(`--kind-history`, 기본 `data/krx/kind`)에서는 상장폐지 목록만 가져온다.
- 재무: 매번 2018년부터 `--end` 전년도 사업보고서까지 수집한다. 사업보고서는 결산 후 15개월이 지나면 쓰이지 않는다(`MAX_FINANCIAL_AGE_MONTHS`). 그래서 2027-04 기록부터는 2026년 사업보고서가 있어야 S3·S4가 종목을 고른다.
- 확인 범위: 판정 함수(공개 시각, 공시 구간, 빈 평일, KIND 분류, 가격 지문, 기업행동 중복)와 `--dry-run` 단계 목록은 테스트로 확인했다. 수집·조립 전체는 네트워크와 실데이터가 필요하므로, 첫 월간 실행(맥)이 첫 실제 확인이다.

- **고정 자본 1억 기준이다 (2026-10-26 확인).** 주문 규모는 `min(평가액, capital_limit)`을 기준으로 정한다(`trading_agent/selection.py`, `RESEARCH_CAPITAL_LIMIT` = 1억). 평가액이 1억을 넘으면 초과분은 투자하지 않고 현금으로 남는다. 그래서 수익은 완전 복리가 아니고, 많이 번 대상일수록 덜 복리된다. 그만큼 대상 사이의 차이도 좁게 나온다. R2의 평균 투자 비중이 0.95보다 낮은 것도 이 때문이다(예: 2025년 +62%로 연말 비중 약 0.59). 매일 목표 비중이 바뀌어 기준 ETF는 거의 매일 조정 매매를 한다. v3~v8의 모든 연구와 C4 판정도 같은 규칙이다. 결과를 본 뒤 평가 규칙을 바꾸지 않기 위해 그대로 둔다.
- 매월 2026-10-21부터 다시 평가한다. 가격은 바뀌면 멈추지만, 기업행동과 종목 상태는 새 공시와 최신 KIND 목록으로 다시 만들어지므로 지난 달 숫자가 조금 바뀔 수 있다. 바뀐 대상은 §5에 적는다.
- 관리종목은 최신 스냅샷 기준이다(정책 1). 두 스냅샷 사이에 지정 해제된 종목은 과거 기간에도 관리종목으로 표시되지 않는다.
- 재무 정정 공시는 정정 값을 원 공시 시각에 쓴다(v7 조립 방식 그대로).
