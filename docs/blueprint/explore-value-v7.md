# 탐색 v7: 가치·수익성 신호와 대형주 유니버스 (2026-10-26 사용자 결정)

작성 2026-10-26, 재무 데이터를 수집하거나 보기 전. 근거는 [전략 대안](strategy-alternatives.md) §3 B1·B2와 v6 §6이다. v3~v6은 모두 가격 신호(모멘텀·반전·저변동성·급등 제외)를 전 종목 상위 10개 구조로 시험했고, 손익이 소형 급등주 몇 개에 몰렸다(v6 관찰 장부 상위 5종목 359%). 이 연구는 **가격이 아닌 재무 신호**와 **시가총액 상위 종목으로 제한한 유니버스**를 시험한다. 결과를 본 뒤 아래 값을 바꾸지 않는다.

## 1. 왜 과거 구간을 다시 쓸 수 있는가

v6 §4대로 2020~2026-10 시세는 모두 "본 구간"이다. 다만 본 것은 가격 신호의 결과이고, 재무 신호는 이 데이터에서 한 번도 계산하거나 평가하지 않았다. 그래서 재무 신호를 미리 정해 두고 과거 구간으로 시험하는 것은 허용한다. 한계도 있다. 2025~26 상승장처럼 시장 흐름은 이미 알고 있으므로, 그 영향은 해석할 때 따로 적는다. 가격 신호의 기간·순위 조합은 이번에 새로 고르지 않는다.

### 2.1 정정 처리 결정 (2026-10-26, 사용자 결정 B, 재무 결과를 보기 전)

맥 탐침(§6 1단계)에서 `fnlttMultiAcnt`는 회사·연도마다 접수번호 하나만 주고, 그 번호는 가장 나중의 공시(정정·재제출)였다. FY2023 기준으로 API 접수일이 원 보고서 최초 접수일보다 늦은 회사는 전체 2,670개 중 17.3%, 2024-04-30 시가총액 상위 200(195개사) 중 42.6%였다. 31일 넘게 늦은 회사는 상위 200 중 9.7%였다. 처음 등록한 규칙(API 접수일 = 공개 시점)대로면 값의 미래 정보는 없다. 그러나 "나중에 정정할 회사"가 그 사이 결정일에 비적격이 된다. 앞으로 정정할지는 그 시점에 알 수 없으므로 이것도 미래 정보에 기댄 편향이고, 4~6월 결정일 유니버스의 약 10%에 영향을 준다. 그래서 공개 시점을 원 보고서 최초 접수일로 바꾸고, 값은 정정 후 값을 쓴다(B).

**표본 확인 (수집기 완성 전, 기준 고정):** 2024-04-30 상위 200 중 API 접수번호가 원 보고서와 다른 회사 전부를 대상으로 한다. 원 보고서의 XBRL 원본(`fnlttXbrl.xml`)에서 자본총계·자산총계·영업이익을 읽어 API 값과 비교한다.
- 비교가 가능한 회사 중 세 계정 가운데 하나라도 1%를 넘게 다른 회사가 **10% 이하이면** B를 확정한다.
- 10%를 넘으면 실행 전에 멈춘다. 그때는 정정된 회사만 원 보고서 XBRL 값을 쓰는 방식(C)을 사람에게 올린다.
- 비교 불가(파일 없음·해석 실패) 비율도 함께 보고한다. 비교 불가가 절반을 넘으면 판정하지 않고 멈춘다.

**표본 확인 결과 (2026-10-26, 맥, HEAD 2bc8106):** 대상 85곳 중 82곳 비교, 3곳은 원 보고서 XBRL 없음(OpenDART status 014: 카카오·영원무역·카카오게임즈, 3.5%). 1%를 넘게 다른 회사는 3곳(3.7%)이다: 고려아연(자산 2.4%·자본 3.0%, 2026-08 재제출), 위메이드(자본 3.6%), 엔켐(영업이익 40.5%, 2026-03 재제출). 나머지 79곳은 차이 0이고, DB하이텍만 0.03%였다. 일부는 계정 2개만 비교됐다(금융사는 API에 영업이익 없음). 기준(10% 이하) 안이므로 **B를 확정한다.** 남는 미래 정보는 이 정도 규모이고, 해석할 때 §7에 적는다.

## 3. 시가총액과 유니버스

- 시가총액 = 결정일 종가 × 그날 FSC 시세의 상장주식수(`lstgStCnt`). 둘 다 그날 장 마감 뒤 공개되는 자료다. [데이터 공급원](data-sources.md) §2.1은 상장주식수를 "진단용, 신호에 쓰지 않음"으로 두었는데, 이 연구에서만 유니버스와 가치 신호에 쓴다. 상장주식수가 없는 날의 종목은 적격이 아니다.
- **유니버스:** 결정일마다 기존 적격 필터(가격·거래대금·상태 등)를 통과한 주식 중 시가총액 상위 200개. 이 제한은 챔피언과 모든 도전자에 똑같이 적용한다. 같은 유니버스에서 비교해야 신호 차이와 유니버스 차이가 섞이지 않는다.

## 4. 사전 등록 값

새 순위 세 가지:

| 순위 | 점수 (높을수록 선택) | 비적격 |
|---|---|---|
| `value` | 자본총계 / 시가총액 (B/M) | 자본총계 ≤ 0 |
| `profitability` | 영업이익 / 자산총계 | 자산총계 ≤ 0 |
| `value_profit` | 유니버스 안에서 위 두 점수의 백분위 순위 평균 | 둘 중 하나라도 비적격 |

- 재무 순위는 기간(lookback)을 쓰지 않는다. 후보는 기간 20 하나만 만든다.
- 챔피언은 momentum/20/top10(v6와 같음)이다. 도전자는 momentum/40, momentum/60, value, profitability, value_profit의 5개이고, 예산은 5다.
- 그 밖의 정책(자본 1억 원, 주문 한도, 매월, 낙폭 한도 25%, 기준 ETF 069500, slippage 25bp, 게이트·통계 정책)은 v6와 같다.
- **고정 전략 평가(판정용):** value_profit/top10을 각 검증 구간에서 별도로 평가한다. 같은 유니버스의 momentum/20/top10도 함께 평가한다. 평가는 읽기 전용 재평가이며 예산을 쓰지 않는다. 에이전트의 선택·게이트와 무관하게 신호 자체를 본다.

## 5. 실행과 판정 기준 (실행 전 고정)

검증 구간은 두 벌이다. 둘 다 통과해야 한다.

- **실행 A (전반부):** 2020-01부터의 입력으로 v5와 같은 검증 구간을 쓴다.
- **실행 B (후반부):** v6 전진 절단 입력(`--first-holdout 2024-07-01`)으로 v6와 같은 검증 구간을 쓴다.

각 실행은 새 DB를 쓰고 검증 예산은 8사이클이다. 실패해도 자동으로 다시 실행하지 않는다.

1. **V1 신호 (주 기준):** 고정 전략 value_profit/top10의 8구간 복리가 A와 B 모두에서 (a) 같은 구간 기준 ETF 복리 이상이고, (b) 같은 유니버스 momentum/20/top10 복리 이상이다.
2. **V2 에이전트:** 재무 순위가 승격되고, 승격 뒤 남은 검증 구간과 관찰 장부에서 기준 ETF 이상이다(v6 기준 1과 같은 형식).
3. **V3 낙폭:** 고정 전략의 관찰 기간 최대 낙폭이 A·B 모두 같은 기간 기준 ETF 낙폭의 1.5배 이하다.
4. **보고만:** value·profitability 단독 고정 평가, 순위별 선택 횟수, 상위 5종목 손익 비중, 결정일 적격 수(재무 자료 보유 비율 포함), 연결·별도 사용 비율, 금융업 등 비적격 비율.

V1과 V3을 모두 충족하면 "전진 기록(새 데이터)으로 확인할 후보"로 판정한다. 그래도 그 자체로 투자 근거가 되지 않는다.

## 7. 해석할 때 주의할 점

- 연구 결과는 E1 참고용이다. 시세 입력의 미해결 기업행동과 관리종목 이력 한계(v6 §5)는 그대로다.
- 사업보고서만 쓰므로 재무 신호는 1년에 한 번(4월 전후) 바뀌고, 그 사이 순위 변화는 가격(시가총액)에서만 온다.
- 정정 후 값을 원 보고서 공개 시점부터 쓴다(§2.1). 표본에서 상위 200 정정 회사의 3.7%가 세 계정 중 하나를 1% 넘게 바꿨다.
- 자본총계에는 비지배지분이 포함된다. 지배주주 지분 기준 B/M과 다를 수 있다.
- 투자 판단에 쓰지 않는다.
