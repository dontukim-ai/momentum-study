# 탐색 후보 공간 v4: 유동성 상위 10종목 (2026-10-25 사용자 결정)

작성 2026-10-25. 근거는 v3b 결과와 분해(explore-candidates-v3 §6, §7)다. 결과를 본 뒤 후보 공간을 바꾸는 제안이라, 새 연구로만 적용하고 기존 연구의 사전 등록은 바꾸지 않는다. 결과를 본 뒤 아래 값을 바꾸지 않는다.

## 1. 왜 바꾸는가

- v3b(5종목)는 검증 구간 8개 복리 −48.0%, 연속 관찰 장부 +101.7%(낙폭 56.0%)로 갈렸다.
- 분해 결과, 관찰 장부 순이익의 124%가 상위 5종목의 한두 달 급등에서 나왔다(§7.2). 급등은 실제 가격 움직임이었다(§7.6). 결과가 소수 종목과 구간 경계에 좌우됐다.
- 이번 질문은 하나다: 집중도를 낮추면(5→10종목) 검증 구간 결과와 낙폭이 나아지는가.

## 2. 사전 등록 값 (사용자 결정 2026-10-25)

| 항목 | v3b | v4 |
| --- | --- | --- |
| 보유 종목 수(챔피언) | 5 | **10** (종목당 약 1,000만 원) |
| 그 밖 | 자본 1억 원, 주문 1건 한도 4,000만 원, 20일 평균 거래대금 하한 100억 원, 매월 리밸런싱, 챔피언 momentum/20, 기간 20/40/60, 낙폭 한도 25%, 기준 ETF 069500, 전략 유니버스 주식만, 편도 slippage 25bp | 같음 |

- 코드 변경 없음. Python 소스가 v3b 실행 빌드(5cd5dfa) 이후 바뀌지 않아 빌드도 같다.
- 연구 이름 `explore-v4-liquid10-1e8`, 새 DB, 검증 예산 8사이클. 실패해도 자동 재실행하지 않는다.

정책 생성:

```
uv run python tools/historical_policy.py --out <dir>/policy.json --top-n 10 \
  --champion-lookback 20 --lookbacks 20,40,60 --max-drawdown 0.25 \
  --decision-cadence monthly --market-etf 069500 --allowed-types STOCK \
  --min-average-turnover 10000000000 --capital 100000000 --max-order-notional 40000000
```

v3b 정책과의 차이는 `top_n` 줄뿐이어야 한다. 다른 차이가 있으면 실행하지 않는다.

## 3. 판정 기준 (실행 전 고정)

에이전트의 승격 게이트는 바꾸지 않는다. 그와 별도로, 이 연구의 해석 기준을 미리 정한다.

1. **개선:** 검증 구간 8개 챔피언 복리가 v3b(−48.0%)보다 높고, 같은 실행의 기준 ETF 복리 이상이다.
2. **집중 위험 감소(보고만):** 관찰 장부 낙폭과 상위 5종목 손익 비중을 v3b(56.0%, 124%)와 비교한다.
3. 1을 만족하지 못하면 종목 수 조정은 멈추고, 신호 자체를 바꾸는 후보(예: 최근 1개월 제외 모멘텀, 다른 팩터)로 넘어간다.

## 4. 해석할 때 주의할 점

v3 §4와 같다: E1 미검증 입력, 미반영 기업행동, 실비용 미확정, ETF 분배금 미반영, 원화 절대 거래대금 하한. 투자 판단에 쓰지 않는다.
