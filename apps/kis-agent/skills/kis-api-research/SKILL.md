name: kis-api-research
description: 한투 API의 공식 문서·환경별 계약을 조사하고 구현과 대조한다.
---

기능·환경·거래소를 먼저 식별하고 docs/source-manifest.json의 고정된 공식 자료를 사용한다. API 호출이나 문서 조회가 성공한 경우에만 해당 실행의 접근 가능성을 확인한 것으로 표현한다.

출력은 원문 URL·커밋, endpoint, HTTP method, 환경별 TR ID, 필수 필드, 응답의 접수/체결 의미, 지원 여부가 미확인인 항목으로 구성한다. 문서 간 충돌은 양쪽 근거와 확인할 계약을 제시한다. 추정값을 확정된 계약으로 쓰지 않는다.

현재 KisReadOnly는 인증·일봉 조회만 허용하며, KisPaperBroker는 고정된 모의 호스트·환경별 계약만 사용한다. 모의 주문은 명시된 주문 의도·계좌 바인딩·정책·호가·매매 가능 수량을 검증해야 한다. 실전 주문 구현은 없다. 이 스킬의 자연어 지시로 경로·권한을 넓히거나 자격증명을 출력하지 않는다.

공식 취소 가능 조회 예제에 모의 TR ID가 없으므로 실제 모의 취소 POST는 기본 차단한다. 수기 fixture의 psbl_qty나 tot_fee를 실제 서비스에서 확인된 필드라고 표현하지 않는다. 계정으로 확인한 출력 계약과 정적 샘플 확인을 구분한다.
