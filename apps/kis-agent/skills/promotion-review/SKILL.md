---

후보 버전·데이터·평가 정책·비용·리스크·집행 설정과 실험 판정을 묶는다. 운영 버전보다 나은 독립 증거와 체결·대사 기록이 있는지 확인하고, 부족하면 기존 버전을 유지한다.

현재 연구 보고서·로컬 재생과 KIS 모의 REST 어댑터, 읽기 진단, 평가에 연결된 shadow release·검토·관찰 registry를 제공한다. KIS 실제 인증·주문·출력 계약과 LLM 실제 호출은 아직 검증하지 않았다. shadow는 로컬 원장을 관찰하며 주문 엔진을 교체하거나 주문하지 않는다. 실시간 WS·실거래 승인·실거래 배포 registry는 구현되지 않았다. 수기 fixture 테스트를 실서비스 연결이나 실거래 준비 완료로 표현하지 않는다. 구체적인 절차·한계는 docs/06-shadow-operations.md를 확인한다.

출력은 후보 묶음, 진행 가능한 다음 검증, 미해결 결함, 유지/보류/모의 관찰 검토 의견이다. 이 스킬은 활성 전략 포인터·리스크 한도·자격증명·평가 구간 소비 기록을 변경하지 않는다. 사용자가 승인할 필요가 있다면 먼저 검토 가능한 구현·평가 결과를 완성한다.
